출발 벨소리

[🔔 준비하기]를 켜 두면 ‘지금 출발!’이 되는 순간 실제 승강장 도착 벨소리(서울교통공사 상선 벨 녹음)와 진동으로 알려 줘요. 브라우저가 백그라운드 소리를 막는 경우가 있어 화면을 켜 두는 게 가장 확실해요.

데이터 소스
data.seoul.go.kr → 실시간 지하철 도착정보(OA-12764) 활용신청 후 발급되는 인증키
worker.js를 Cloudflare Workers에 올리고 주소를 넣으세요. 키를 Worker 환경변수(SEOUL_API_KEY)에 두면 앱에는 키를 저장하지 않아도 됩니다.

데모 모드는 API 키가 없어도 출발역 방향 열차가 실제처럼 흐르는 화면을 보여 줍니다. 키나 프록시를 저장하면 바로 실데이터로 바뀌고, 실패하면 데모로 되돌아갑니다.
